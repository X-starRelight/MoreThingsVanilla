## 阅读路径

- **第一次玩**：按[快速上手](getting-started.md)做一个座位，再试试把[坐垫](cushion.md)放在下半砖上。
- **查建筑材料**：直接翻[方块全表](blocks.md)，按中文名或 ID 查找；表前的配方说明区分了哪些材质能染、哪些能切。
- **搭跨层电路**：先用[竖直红石](redstone.md)把信号送上楼，再用[单向传递器](one-way-transmitter.md)把信号分给几个房间。
- **给地下室开天窗**：用[天空盒方块](sky-box.md)在天花板上镶一片天空，白天也能看到云和太阳。
- **做不会传送的末地门**：用[末地盒方块](end-box.md)拼出门框，得到原版传送门的星空外观。

## 如何阅读原版参考

坐垫是唯一完整复刻的原版内容。台阶与楼梯沿用原版形状，文档重点是本 Mod **多加了哪些材质**。红石粉、中继器、比较器的 Wiki 条目用于解释原版术语；本 Mod 的三个竖直组件是原创方块，实际接线以[竖直红石指南](redstone.md)为准。天空盒方块的效果参考社区 Mod「Block of Sky」，原版没有对应方块，用法以[天空盒指南](sky-box.md)为准。末地盒方块复用原版末地传送门的纹理与动画，外观可对照原版 Wiki 的末地传送门条目，用法见[末地盒指南](end-box.md)。
