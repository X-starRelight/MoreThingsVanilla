# 天空盒方块

天空盒方块是一块会显示天空的建材。方块本体不可见，六个面显示的是**当前世界里、你视线方向上的那片天空**：太阳、月亮、星星、日出日落和云都按世界时间实时变化。把几块拼在一起，天空会连成一片，像在天花板上开了一扇窗。

## 1. 合成

在工作台正中放 **1 支普通火把**，周围八格各放 **1 块普通玻璃**，一次得到 **8 个天空盒方块**。

| 工作台 | 天空盒方块 |
|---|---|
| 上排 | 普通玻璃、普通玻璃、普通玻璃 |
| 中排 | 普通玻璃、普通火把、普通玻璃 |
| 下排 | 普通玻璃、普通玻璃、普通玻璃 |

生存模式第一次同时带着这两样材料时，配方会自动加入配方书。

## 2. 特性

| 项目 | 数值或行为 |
|---|---|
| 硬度 | 1.5，与石头相同；不需要特定工具，空手也能挖掉 |
| 爆炸抗性 | 6.0，比玻璃结实，近距离苦力怕爆炸仍会造成破坏 |
| 发光 | 恒定 15 级方块光，白天黑夜都一样 |
| 活塞 | 不可推动，也不能被黏性活塞拉走 |
| 光线 | 不挡光，也不遮挡相邻方块的面 |
| 外观 | 方块本体透明，只有显示天空的六个面 |

想临时遮住天空，可以在它前面放普通方块；想拆掉，用镐挖掉即可，会掉落自身。

## 3. 拼出连续的天空

- **方向跟着视线走**：方块里显示的不是固定贴图。你从哪个方向看过去，看到的就是那个方向上的天空。左右移动视角时，云和太阳会像隔着真窗户一样自然移动。
- **相邻方块自动接缝**：两块天空盒挨在一起时，公共面会被隐藏，只保留朝外的面。拼 2×2×2 的立方体，看到的也只是完整外壳，不会出现内部重叠的天空。
- **大面积铺开**：把天空盒排成天花板或整面墙，接缝处仍然是一片连续的天空；单独放一块则像一个方形取景框。

## 4. 各维度的效果

| 维度 | 方块里显示什么 |
|---|---|
| 主世界 | 当前时刻的天空，含日、月、星、日出日落与云 |
| 末地 | 末地天空，包括末影龙刷新时的闪光 |
| 下界等无天空维度 | 该维度的雾色天空：下界通常为暗红，不同生物群系色调略有差异；没有日、月、星、云 |

云层是否出现跟随「视频设置 → 云」的开关；关闭云以后，方块里的天空也不再显示云。

## 5. 常见用法

- **地下假天窗**：在房间天花板镶一片天空盒，再在中间留一格放萤石或海晶灯，白天也有自然光感。
- **封闭建筑的采光顶**：不用真的开洞，就能让室内看到天空与云，同时保持建筑完整。
- **装饰画框**：单独嵌一块在墙上，当作会随时间变化的方形风景。
