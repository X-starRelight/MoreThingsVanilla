# 末地盒方块

末地盒方块（`more-things-vanilla:end_box`）把原版末地传送门那层流动的星空，做成了一块完整的立方体建材。方块有整格碰撞，站上去、撞上去都不会传送；六个外表面显示的是和末地传送门同一套动态效果。

## 1. 获取

在工作台中放 **1 个天空盒方块**，再放 **1 块末地石**，得到 **1 个末地盒方块**。

生存模式第一次同时带着这两样材料时，配方会自动加入配方书。

## 2. 特性

| 项目 | 数值或行为 |
|---|---|
| 硬度 | 1.5，与石头相同；不需要特定工具，空手也能挖掉 |
| 爆炸抗性 | 6.0 |
| 发光 | 恒定 15 级方块光，白天黑夜都一样 |
| 碰撞 | 完整一格，可以站立、可以贴墙 |
| 传送 | 不会传送，和普通方块一样 |
| 活塞 | 不可推动，也不能被黏性活塞拉走 |
| 光线 | 不挡光，也不遮挡相邻方块的面 |
| 外观 | 六个外表面显示原版末地传送门的动态星空 |

挖掉后会掉落自身。

## 3. 外观与拼接

- **原版效果**：星空纹理和动画直接复用原版末地传送门，颜色、流动速度和闪烁节奏都与游戏里的末地传送门一致。
- **六面完整**：方块的上下前后左右六个面都会显示星空，不像传送门方块那样只在一个平面出现。
- **相邻自动接缝**：两块末地盒挨在一起时，公共面会被隐藏，只保留朝外的面；拼成 2×2×2 也只会看到完整外壳。
- **物品外观**：背包和手中同样显示为一块动态星空立方体。

## 4. 常见用法

- **末地风格装饰**：在末地石建筑、黑曜石大厅里镶几块，当作会流动的灯箱。
- **安全传送门造型**：搭出门框后填入末地盒，得到不会把人吸走的传送门外观。
- **地板与天花板**：整片铺开做发光地面，或嵌在天花板上当作星空顶。
