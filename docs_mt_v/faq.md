# 常见问题

### 创造物品栏里找不到新增方块，先查什么？

确认启动的是装有 Mod 的 **26.2 Fabric 实例**，并在创造模式查看「更多内容-原版」标签页。用中文搜索台阶时，游戏内名称写作「半砖」。若游戏尚未启动就报缺少依赖，按[安装步骤](getting-started.md)核对 Loader、Java、Fabric API 和 JAR 所在目录。

### 为什么有 40 种楼梯，却只有 39 种半砖？

差额是平滑石头楼梯。原版已经有平滑石头台阶，本 Mod 只补楼梯。其余材质均成对添加，可在[建筑方块全表](blocks.md)中按 ID 查找。

### 为什么混凝土半砖不能像羊毛半砖一样改色？

本 Mod 的建材染色配方适用于羊毛半砖和羊毛楼梯。制作另一种颜色的混凝土半砖时，先取得目标颜色的硬化混凝土，再用工作台或切石机加工。混凝土粉末不能直接替代硬化混凝土。

### 朝上的比较器该从哪边读箱子？

输出朝上时，正后方就是下方，把箱子放在比较器下方。先断开侧输入测试：非空箱子应有读数。重新接入侧线后，侧输入较强可能让比较模式的输出降为零。[朝向与箱子示例](redstone.md)

### 单向传递器两端都来过电，为什么关掉一路还是没有输出？

如果在选输入面时同时检测到多面带电，本轮会被阻止。让所有面都断电，等相邻线路退电，再只从需要的一面送入信号。换输入面和切换输出强度模式是两件事，具体见[单向传递器](one-way-transmitter.md)。

### 坐垫占用一个方块格吗？

不占。物品放下后生成可乘坐的实体，可以贴着半砖顶面摆放。请对准支撑面的顶部，而非墙的侧面。见[放置与回收](cushion.md)。

### 26.2 存档现在就需要把彩色建材改成原版 ID 吗？

不需要。在 26.2 中继续保留本 Mod 和 `more-things-vanilla:` ID。64 个羊毛、混凝土半砖与楼梯的 ID 转换是 **26.4 构建计划**，当前版本没有迁移器；这项计划也不涉及矿物建筑方块或红石组件。今后升级前先备份世界，并以目标版本的发布说明为准。
