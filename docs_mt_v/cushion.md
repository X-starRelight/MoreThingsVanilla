# 坐垫

坐垫是本模组唯一完整复刻的原版内容，原型见[《我的世界》中文维基：坐垫](https://zh.minecraft.wiki/w/坐垫)。甚至 Bug 也复刻了原版！  
放下的坐垫是一个可供一名玩家坐下的实体，宽一格、高四分之一格。

## 1. 制作与换色

| 想做什么 | 材料与摆法 | 结果 |
|---|---|---|
| 制作坐垫 | 在工作台的同一行摆满三个同色羊毛半砖 | 一个同色坐垫 |
| 给坐垫换色 | 把一个坐垫和一份不同颜色的染料放进合成栏，位置不限 | 一个与染料同色的坐垫 |

坐垫有白色、淡灰色、灰色、黑色、棕色、红色、橙色、黄色、黄绿色、绿色、青色、淡蓝色、蓝色、紫色、品红色和粉红色，共十六色。同色坐垫每组最多十六个。

例如，想在桌子两侧各放一个座位，可以用六个白色羊毛半砖分两次合成，留一个白色坐垫，再把另一个和蓝色染料放进随身合成栏，做成蓝色坐垫。

## 2. 放置、坐下与起身

1. **放置：**手持坐垫，瞄准方块的上表面按使用键。坐垫会水平居中，高度则取决于点到的表面。例如，点下半砖的顶面，坐垫就会贴着半砖，而不会悬在一整格高的位置。点击侧面或底面无法放置，两个坐垫也不能重叠。
2. **坐下：**松开潜行键，对空坐垫按使用键即可入座，不必空手。已有玩家坐着时，其他人无法挤上同一个坐垫。
3. **起身：**按潜行键离座，坐垫会留在原处。放置、坐下、起身和破坏各有对应的音效。

## 3. 回收与其他用途

- **搬动座位：**在生存模式下攻击坐垫即可拆下；开启实体掉落时，会掉落原色坐垫。创造模式下直接打掉不会掉落物品，想取同色坐垫可对准它使用选取键。
- **拆掉底座：**坐垫约每五秒检查一次支撑。比如拆掉座位下方唯一的半砖后，它可能短暂悬空，随后掉落。坐垫被会造成窒息的方块完全覆盖时也会被破坏。
- **遇火或雷击：**放进火里的坐垫会立即损坏；已经放好的坐垫也会定期检查火焰。雷击会破坏坐垫，雷击产生的掉落物有约一秒的伤害保护。
- **充当燃料：**一个坐垫能在熔炉中燃烧五十游戏刻；连续投入四个，刚好能烧炼一个普通物品。
