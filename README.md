# MoreThingsVanilla

Fabric Mod：在原版基础上添加竖直红石（粉/中继器/比较器）、坐垫，以及缺失材质的半砖与楼梯。

- 设计文档：[`设计.md`](设计.md)
- 实现计划：`docs/superpowers/plans/`

## 构建

```powershell
.\gradlew.bat build
```

产物位于 `build/libs/`。运行开发客户端：`.\gradlew.bat runClient`；运行 gametest：`.\gradlew.bat runGametest`。
